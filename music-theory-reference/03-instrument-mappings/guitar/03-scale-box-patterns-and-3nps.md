# 03 Scale Box Patterns and 3NPS

This module covers two common ways guitarists organize scales across the fretboard:

- The **5-box position system**
- The **3-notes-per-string (3NPS) system**

Both are guitar-specific and depend on the fretboard coordinates and standard tuning from `01-fretboard-layout-and-standard-tuning`. Neither is instrument-agnostic.

## 1. Why Two Systems

Scale patterns on guitar are not just “the scale written in order.” Because the guitar has six strings and frets, how notes fall under the hand determines what patterns are practical.

The two main systems differ in:

- **Note density per string**: how many scale notes each string carries
- **Hand geometry**: finger spacing, stretches, and repetitions
- **Patterns and symmetry**: how the scale repeats and shifts across strings
- **Voice-leading and melodic flow**: how the pattern connects up and down the neck

Most players benefit from knowing both, because each has strengths depending on the musical context.

## 2. The 5-Box Position System

The 5-box system divides the fretboard into five interlocking **positions** for a given scale, usually defined by which fret the “first finger” occupies and which strings are in primary use.

### Core Idea

- The scale is learned in five movable “boxes.”
- Each box emphasizes a region of the neck where a comfortable hand frame reaches most of the scale notes around a given position.
- The boxes connect and overlap, so the full scale is covered across the neck.

### Why Five Boxes

A common reason for five boxes is that they cover the scale across the whole neck using manageable hand spans, with roots on different strings in different boxes. Each box gives a different “view” of the same scale.

### Box Character

In each box:

- Certain strings carry more notes in the hand frame.
- Some fingers repeat patterns.
- There is typically one root located clearly in the box, often on a specific string, giving the box a “root identity.”
- The shapes are movable: slide the whole box up or down the neck to change keys.

### Strengths

- Comfortable, localized hand positions
- Easy to start improvising in a small region
- Strong connection to common lead-guitar vocabulary
- Good for learning the scale in small pieces

### Weaknesses

- Can emphasize patterns over the whole neck, so players may “stay in one box”
- The fretboard connectivity may feel less continuous than in 3NPS

## 3. The 3NPS System

**3NPS** means each string contains **three notes** of the scale before moving to the next string.

### Core Idea

- The scale is arranged so that each string holds three notes in a consistent pattern.
- The pattern repeats across strings, producing a very regular, vertically flowing layout.
- It is especially popular for sweeping, legato, and pattern-based lead playing.

### Why Three Notes Per String

Three notes per string is a convenient density:

- Not too crowded to finger comfortably
- Regular enough to produce a repeating, predictable pattern
- Wide enough to cover the scale across the neck with a structured layout

One practical feature: because the pattern is symmetrical across strings, it often gives a clearer “vertical flow” of the scale, especially when ascending or descending across multiple strings.

### Strengths

- Highly regular, easy to visualize across the neck
- Good for speed-oriented techniques (legato, sweep, picking sequences)
- Emphasizes consistent fingering patterns
- Useful for seeing how the scale moves across all strings

### Weaknesses

- Can be more spread out in the hand
- May be less about “localized positions” and more about global mapping
- In some styles, the hand shifts more than in box-based playing

## 4. ASCII Diagram Sketch: A Generic Scale “Box”

A very schematic box diagram uses vertical lines for strings and frets along one axis:

```
      5   6   7   8
E ─────●───────●───────
B ────────────●───────●──
G ──────●───────●───────
D ────────────●───────●──
A ──────●───────●───────
E ────────────●───────●──
```

Here `●` marks scale notes in that abstract region. This is illustrative, not a literal key-specific diagram; the pattern of note placement is what matters.

Important: a real box diagram should be tied to a specific scale and position, because note locations depend on both the scale and the starting fret.

## 5. ASCII Sketch: A Generic 3NPS Pattern

A generic 3NPS concept:

```
      5   6   7   8   9
E ──────●───●───●─────────
B ──────────●───●───●─────
G ──────●───●───●─────────
D ──────────●───●───●─────
A ──────●───●───●─────────
E ──────────●───●───●─────
```

In 3NPS, each string carries three note markers, and the pattern is “staggered” so the hand moves in a regular way across strings.

As with the box sketch, this is conceptual: actual note identities depend on which scale and where you start.

## 6. Roots and Orientation

Both systems need clear root references:

- In boxes, one or more roots in the shape help you orient the scale.
- In 3NPS, roots still appear at particular places across the pattern, even though the shape is more spread out.

Without knowing where the root lands, a pattern is just a shape, not a scale in a key.

## 7. Patterns vs. Notes

It is easy to memorize a pattern without knowing the notes it contains. For real fretboard fluency:

- Learn the note names under the pattern.
- Learn the scale degrees relative to the root.
- Learn how the pattern moves when you change key.
- Learn how the same scale appears in both the box system and 3NPS.

Patterns are tools, not substitutes for knowing the fretboard.

## 8. Comparison at a Glance

| Aspect                 | 5-Box system                        | 3NPS system                       |
|------------------------|--------------------------------------|-----------------------------------|
| Notes per string       | Varies by box                        | Typically 3 per string            |
| Hand frame             | More localized, compact in each box  | More regular across strings       |
| Best for               | Position play, blues/rock licks      | Sweep/legato, patterned runs      |
| Neck coverage          | Incremental across 5 boxes           | Continuous vertical flow          |
| Learnability           | Often easiest as a first approach    | May feel more systematic later    |

Neither system is “correct” or “incorrect” — they are different mappings of the same scale onto the same fretboard.

## 9. Using Both Systems Together

A common workflow:

- Learn the scale in a 5-box style to get local, playable regions and comfortable licks.
- Learn the same scale in 3NPS to see the full neck structure and build speed patterns.
- Practice moving from one system to the other so your fretboard knowledge does not depend on a single shape vocabulary.

The more flexibly you can see the same scale in different layouts, the less likely you are to get trapped in one position or pattern.

## 10. Relationship to CAGED

CAGED (see `02-caged-system-and-movable-shapes`) and these scale systems are closely related:

- Each CAGED shape can be associated with scale regions.
- Boxes and 3NPS often map onto the same fretboard geography from a different perspective.
- Together, they help integrate chords, arpeggios, and scales into one fretboard map.

The unification is a big part of why these systems coexist in modern guitar pedagogy.

## 11. Summary

- The 5-box system organizes a scale into five interlocking, movable positions.
- 3NPS organizes a scale into a regular three-notes-per-string layout across the neck.
- Boxes favor localized comfort and pattern vocabulary; 3NPS favors vertical regularity and pattern flow.
- Both depend on root identification and actual note knowledge, not just shapes.
- Learning both gives the most flexible fretboard map for the same underlying scale.
